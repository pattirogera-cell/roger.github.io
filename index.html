Guía Práctica: C# 5.0

Novedades clave y ejemplos para Visual Studio (.NET Framework 4.5)

1. Introducción a C# 5.0

Lanzado junto con Visual Studio 2012 y .NET Framework 4.5, C# 5.0 revolucionó la programación asíncrona mediante la introducción del patrón Async / Await.

2. Programación Asíncrona (Lo más importante)

Antes de C# 5, manejar hilos y callbacks requería un código complejo (IAsyncResult, BackgroundWorker). Con async y await, el código asíncrono se escribe de forma secuencial y limpia.

Ejemplo de código:

using System;
using System.Net.Http;
using System.Threading.Tasks;

class Program
{
    // El método debe marcarse como async
    static async Task Main(string[] args)
    {
        Console.WriteLine("Descargando contenido...");
        
        string resultado = await DescargarPaginaAsync("https://example.com");
        
        Console.WriteLine($"Longitud del contenido: {resultado.Length}");
    }

    static async Task<string> DescargarPaginaAsync(string url)
    {
        using (HttpClient client = new HttpClient())
        {
            // "await" libera el hilo principal mientras espera la respuesta de la red
            string html = await client.GetStringAsync(url);
            return html;
        }
    }
}

3. Atributos de Información del Llamador (Caller Info Attributes)

Permite obtener información sobre el método invocador, el archivo fuente y el número de línea sin recurrir a la reflexión. Es ideal para depuración y registros (logging).

Ejemplo de código:

using System;
using System.Runtime.CompilerServices;

class Logger
{
    public static void Log(
        string mensaje,
        [CallerMemberName] string metodo = "",
        [CallerFilePath] string archivo = "",
        [CallerLineNumber] int linea = 0)
    {
        Console.WriteLine($"[MENSAJE]: {mensaje}");
        Console.WriteLine($"[MÉTODO]:  {metodo}");
        Console.WriteLine($"[ARCHIVO]: {archivo}");
        Console.WriteLine($"[LÍNEA]:   {linea}");
    }
}

class Program
{
    static void Main()
    {
        // Al llamar a Log(), el compilador inyecta automáticamente los datos
        Logger.Log("Ocurrió un evento importante.");
    }
}

4. Captura de Variables de Bucle (Foreach Loop Bound Variables)

En C# 5 se corrigió un comportamiento confuso en las expresiones Lambda dentro de bucles foreach. En C# 4, la variable de iteración se compartía entre todas las iteraciones; en C# 5, cada iteración obtiene su propia copia.

Diferencia:

var acciones = new List<Action>();
var numeros = new[] { 1, 2, 3 };

foreach (var n in numeros)
{
    acciones.Add(() => Console.WriteLine(n));
}

foreach (var accion in acciones)
{
    accion();
}

// Resultado en C# 4: 3 3 3 (Problema conocido)
// Resultado en C# 5: 1 2 3 (Corregido automáticamente)
